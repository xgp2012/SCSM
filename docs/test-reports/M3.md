### 3.2 UDP 探测协议（实测确定，取代此前推断）

源码分析 + 编译产物实测确认协议如下（plants.md §0.3 / §11-Q3）：

- **单播**探测（不依赖 `BroadcastPort`，后者在编译产物中不存在，仅 `ServerPort`）。
- 请求 UDP 载荷：`[0x09][RAW-DEFLATE(0x88, 0x00, 0x01)]`
  - `0x09` = LiteNetLib `PacketProperty.UnconnectedMessage`
  - `0x88` = SC 包标记；`0x00` = `PackageType.ServerInfo`；`0x01` = `requestInfo=true`
  - 压缩为 .NET `DeflateStream`（raw deflate，无 zlib 头）→ Node `zlib.deflateRawSync`
- 回执 UDP 载荷：`[0x09][RAW-DEFLATE(0x88, 0x00, 0x00, version, u16 clientCount, u16 maxPlayerCount, u8 gameMode, bool needLogin, bool needPasswd, f32 timeOfDay)]`

实测回执示例（内层解压后 hex）：

```
88 00 00 09 7832362e30362e3139 0000 1400 02 00 00 <f32>
^marker ^id ^req=false ^len=9 "x26.06.19"  ^cnt=0 ^max=20 ^mode=2 ^needLogin ^needPasswd ^timeOfDay
```

解析结果：`version=x26.06.19, playerCount=0, maxCount=20, gameMode=Survival, needPassword=false, timeOfDay≈0.35`，
与实例 `ServerSetting.json`（`WorldMaxPlayers=20`、`GameMode`）一致。

> **发现**：错误封装（如未包裹 LiteNetLib property 字节）会被 LiteNetLib 以 `PeerNotFound(0x0f)`
> 拒绝或静默丢弃；正确封装方可收到 ServerInfo 回执。门禁脚本**独立实现**该协议（不 import 后端代码），
> 证明第三方可复现。

### 3.3 系统指标（真实采样）

`GET /system/stats` 返回主机 CPU/内存/磁盘（`node:os` + `fs.statfs`，零外部依赖）：

```
{"cpu":75.95,"memPercent":42.21,"memUsedMB":3407,"memTotalMB":8073,"diskPercent":37.52,
 "diskUsedMB":..., "diskTotalMB":...,"cpuCount":4,"platform":"win32","uptimeSec":...,"loadAvg":[...],"ts":...}
```

CPU 为两次采样之间增量（首次为 0），随负载变化（实测 75.95 → 18.58）。

### 3.4 实例进程指标（真实采样）

WS `instance.stats`：`cpu=0% mem=309.95MB`（真实 `dotnet` 进程常驻内存约 300MB）。
- Windows 经 `wmic process ... KernelModeTime,UserModeTime,WorkingSetSize` 采集；
  缺失时回退 `powershell Get-Process`。
- Linux 经 `/proc/<pid>/stat` + `/proc/<pid>/status`。

### 3.5 探测结果经 REST 即时返回

`GET /api/instances/:id/probe` 返回与独立脚本一致的 `online/version/playerCount/...`。

### 3.6 WS 双推送

- `player.list`：`online/maxOnline/gameMode/hasPassword/probeOnline/version/timeOfDay/pingMs`。
- `instance.stats`：`cpu/memMB/ts`。
- `system.stats`：主机级，广播给所有 WS 连接。

### 3.7 运行时聚合

`GET /api/instances/:id` 的 `runtime` 含 `online/maxOnline/gameMode/cpu/memMB/probeOnline/lastProbeAt/timeOfDay`，
概览卡片与详情页直接消费，无需额外请求。

### 3.8 停止清理

实例停止后 `runtime.probeOnline=false`、`memMB/cpu` 清空，避免陈旧数据。
