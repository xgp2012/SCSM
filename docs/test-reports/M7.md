## 4. 限流（§9）

| 位置 | 策略 | 实测 |
|------|------|------|
| 全局 | 每 IP 每分 300 次（`ThrottlerModule.forRoot`） | 生效 |
| `POST /auth/login` | 每 IP 每分 **5** 次（`@Throttle`） | E2E / `m7-gate` 连续错误登录 → **429** |
| `POST /versions/download` / `upload` | 每 IP 每分 10 次 | 配置生效 |
| `POST /instances/:id/:action` | 每 IP 每分 30 次 | 配置生效 |
| WS `console.command` / `console.write` | 每连接 10s 内 40 条，超限回 `error: rate_limited` | 网关计数生效 |

> 守卫顺序：`ThrottlerGuard` 先于 `JwtAuthGuard`，避免未鉴权请求绕过限流。
