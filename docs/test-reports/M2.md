### 3.3 WS 双通道与回放

- `console.raw`：原样 ANSI 字节流（含 `\u001B[?...` 光标控制），供 xterm.js 渲染。
- `console.line`：清洗后的纯文本行，供日志/检索/事件匹配。
- 连接即下发 `console.history`（纯文本行 + ANSI 快照）与 `console.hello`（运行时快照）；
  另有 REST `GET /api/instances/:id/history` 供首屏/回退。

### 3.4 `/help` 真实回执（raw 去 ANSI）


命令经 `console.command` → 网关补 `/` 前缀 + `\r` → `pty.write`；回执走 raw/line。

### 3.5 ANSI / resize

- 服务端增强控制台整屏重绘使用 ANSI 光标控制序列，raw 通道完整保留；
  xterm.js 消费后即为正确彩色画面（不降级、不乱码）。
- 前端 `terminal.onResize → socket.resize → pty.resize`；门禁验证 resize 帧无异常。

### 3.6 多观察者一致性

第二个 WS 连接（同实例）：收到 **49 行历史回放** + 后续 **47 帧实时输出**，
与首个观察者一致；命令写入经每连接队列 + 16ms 合帧，避免交叉错乱。

## 5. 交付物（M2）

- **后端（apps/api/src/console/）**：
  - `console.gateway.ts`：`@WebSocketGateway({ path: '/ws/console' })`，Cookie/Bearer
    握手鉴权（`AuthService.verify`），实例存在性校验；连接下发 history/hello；
    处理 `console.write`/`console.command`/`terminal.resize`/`ping`；命令队列化 + 16ms 合帧；
    多观察者订阅扇出。
  - `console.service.ts`：订阅 `InstanceSupervisor` 的 `raw`/`line`/`status` 事件，
    填充回滚缓冲并扇出给该实例全部订阅者（单订阅者异常隔离）。
  - `rollback-buffer.ts`：双通道环形缓冲（5000 行 + 64KB ANSI，带 RESET 前缀快照）。
  - `console.controller.ts`：`GET /api/instances/:id/history`。
  - `console.module.ts`；`main.ts` 接入 `WsAdapter`。
- **共享类型（packages/shared/src/ws.ts）**：`console.history`/`console.hello`/`error`
  帧、客户端消息接口、`CONSOLE_HISTORY_LINES`/`CONSOLE_HISTORY_ANSI_BYTES`。
- **前端（apps/web）**：
  - `composables/useConsoleSocket.ts`：复用 HttpOnly Cookie 的 WS 客户端，事件分发。
  - `components/console/TerminalView.vue`：`@xterm/xterm` + `@xterm/addon-fit`
    （+ search 已装），动态导入避免 SSR，容器 ResizeObserver → fit → resize 帧，
    命令输入框（自动补 `/`）、清屏、重连、状态灯。
  - `pages/instances/[id].vue`：终端标签接入 `TerminalView`，移除占位。
- **运维**：`apps/api/scripts/m2-gate.cjs`（门禁脚本）、`docs/test-reports/M2.md`（本文件）。
