## 3. 端到端功能验证（真实启服）

驱动脚本对运行中的 API 发真实 HTTP 请求；服务端进程经 **node-pty（ConPTY）** 启动。

### 3.1 认证

```
[gate] 未登录 GET /instances => 401 (期望 401)
[gate] 错误密码登录 => 401 (期望 401)
[gate] 正确登录 => 201 (期望 201), user=admin
[gate] GET /auth/me => 200, role=admin
```

- 登录通过 `Set-Cookie: sc_panel_token=...; HttpOnly; SameSite=Lax` 下发 JWT。
- 全局 `JwtAuthGuard` 保护除 `@Public()`（`/auth/login`、`/health`）外的全部 REST。

### 3.2 独立实例目录初始化

```
[gate] 模板: exists=true hasBinary=true version=2.4.0.0-ljx26.06.19
[gate] 创建实例 A id=cb48afcb port=28887 dir=...\data\instances\cb48afcb-...
[gate] 创建实例 B id=d5c8a76a port=28898 dir=...\data\instances\d5c8a76a-...
```

- `source=template`：递归拷贝模板目录 → 清理 `Bugs/Game.log` 运行期残留。
- `source=upload`：上传 zip（实测 22.8 MB）解压 + 单层目录规整 + 校验 `Survivalcraft.dll`。
- `source=import`：引用既有目录并校验二进制存在。

### 3.3 启动特征（服务端真实日志）

服务端 `Bugs/Game.log`（实例 47a968c9，端口 28898）：


### 3.4 配置写回（端口 / 世界人数）


- `Settings.xml` 仅改 `ServerPort`，**未知条目/顺序保留**（`<DisableMods/>`、`<Configs/>` 原样）。
- `ServerSetting.json` 浅合并 `WorldMaxPlayers/WorldName/Autorun`，未知键保留。
- 重启后服务端日志/运行时端口 = 28922，与配置一致。

### 3.5 真实进程 + 双实例并行（不同端口）


两个实例各自绑定独立 UDP 端口（28961 / 28962），PID 与端口一一对应，互不干扰。

### 3.6 状态机（服务端权威日志）

```
[Supervisor] [c2fd5a32-...] status → starting
[Supervisor] [c2fd5a32-...] 服务端开启成功，端口 28911
[Supervisor] [c2fd5a32-...] status → running
[Supervisor] [c2fd5a32-...] status → stopping
[Supervisor] [c2fd5a32-...] status → stopped
```

完整流转 `stopped(初始)→starting→running→stopping→stopped` 成立。
停止优先写 `/stop`，15s 超时后强杀（`STOP_GRACE_MS` 可配）。

### 3.7 崩溃检测 + 自动重启

```
[gate2] 已运行 pid=14476 serverPort=28901
[gate2] 外部 taskkill /PID 14476 模拟崩溃 ...
[gate2]   status=crashed            ← 非预期退出识别为 crashed
[gate2] 等待自动重启 ...
[gate2]   status=starting
[gate2]   status=running            ← autoRestart 退避 5s 后拉起
[gate2] === 崩溃检测 + 自动重启 通过 ===
```

- **正常停止 → `stopped`** 与 **崩溃 → `crashed`** 通过 `intentionalStop` 区分。
- `autoRestart` 指数退避（5s 起，上限 60s）。

## 5. 交付物（M1）

- **后端**：
  - `auth/`：登录/登出/me、JWT HttpOnly Cookie、全局 `JwtAuthGuard`、`@Public()`。
  - `server-config/`：`Settings.xml`（XML，保留未知条目/顺序，原子写）与
    `ServerSetting.json`（浅合并）读写。
  - `adapter/`：`IServerAdapter` 接口 + `PtyAdapter`（node-pty，raw/line 双通道、
    resize、`/stop` 优雅停止）+ `LineSplitter`/`stripAnsi`。
  - `instance/`：`InstanceStore`（JSON 原子写）、`InstanceSupervisor`（状态机/崩溃/
    自动重启/`FileTailer`）、`InstanceService`（CRUD、模板拷贝/zip 解压/导入、
    端口分配、配置写回）、REST 控制器与 DTO。
  - 环境/工具：`EnvModule`（强类型 `PanelEnv`）、`resolveExecutable`
    （Windows ConPTY 需绝对路径）、`toAbsolute`。
- **共享类型**：`auth.ts`、扩展 `instance.ts`（`source`/`UpdateInstanceInput`/
  `InstanceAction`/`OverviewResponse`/`TemplateInfo`）；`shared` 改为 **ESM+CJS 双产物**。
- **前端（Nuxt4 SPA）**：`login.vue`、`index.vue`（概览卡片 + 启停）、
  `instances/[id].vue`（详情骨架 + 设置 + 轮询状态）、`layouts/{default,blank}.vue`、
  `middleware/auth.global.ts`、`composables/useApi.ts`、`stores/instances.ts`、
  `components/instance/{InstanceCard,CreateInstanceDialog,StatusDot,StatTile}.vue`。
- **运维**：`docs/test-reports/M1.md`（本文件）。
