### 3.2 releases 列表（Gitee API）

`GET /api/versions/releases` 拉取 `GET https://gitee.com/api/v5/repos/SC-SPM/SurvivalcraftNet/releases`，
映射为共享 `ReleaseInfo` 并标注每个 asset 的 `isServerPackage/platform/arch/isSourceArchive`：

```
releases=2 host=windows fallback=false
```

实测 2 个 release：`x26.06.19`（8 assets）、`x26.07.01.01`（9 assets）。服务端包识别规则：
命中「服务端」关键字且非电脑版/安卓版/源码自动归档；自动排除 `[电脑版]`、`[安卓版]`、`.apk`
与 `archive/refs/tags/` 源码 zip。

### 3.3 缓存与强制刷新

- `VERSION_CACHE_MS`（默认 300000）内二次请求返回 `cached=true`。
- `POST /api/versions/releases/refresh` 清缓存并重新拉取。
- 拉取失败时**降级到本地缓存** `data/versions/releases-cache-{source}.json` 并带可读 `notice`；
  无缓存则返回 `fallback=true` + 「可改用手动上传」提示（界面展示，见 §4）。

### 3.4 下载 → 解压 → 安装（真实 Gitee 包）

`POST /api/versions/download { tag, asset, mode:'new' }` 立即返回 `taskId`，后台执行：
流式下载（跟随 302、带 Referer/UA）→ 写入暂存 → 最新 release 优先选托管式 Survivalcraft 包 →
解压到 `data/instances/<id>` → 单层目录上移 → 校验 `Survivalcraft.dll` → 注册实例（端口/配置）。

```
phase=done bytes=23114052 instance=m6-gate-...
```

### 3.5 下载安装的新实例可成功启动（门禁核心）

实测 PTY 启动日志（下载得到的 `[服务端]SCNETx26.06.19z1.zip`）：

```
18:19:22.588 INFO: Entered screen "Play"
18:19:22.711 INFO: 自动生成存档已启用，正在检查存档目录...
18:19:23.107 INFO: [StartServer]开启服务器成功，端口 28889
18:19:23.887 INFO: Loaded world, GameMode=Harmless, StartingPosition=Easy, WorldName=ScWorld
18:19:23.952 INFO: Entered screen "Game"
```

Supervisor 推进 `starting → running`（port 28889），门禁第 2 条通过。

> **关键工程点（实测）**：下载的版本包**不含世界存档**（`Worlds/`）与 `Settings.xml`/
> `ServerSetting.json`。面板安装时须**播种默认配置**：`ServerPort`、`Autorun=true`，
> 且当世界目录不存在时置 **`AutoGenerateWorld=true`**，否则服务端会因
> 「自动运行存档不存在」直接退出（实测错误日志 `自动运行存档不存在, 已终止程序`）。

### 3.6 服务端包排序（避免误装变体）

实测同一 release 存在多种「服务端」资产，面板按评分优先托管式 Survivalcraft 包：

| 资产 | 形态 | 评分 |
|------|------|------|
| `服务端X26.07.01.01.zip` | `net10.0/Survivalcraft.dll`（托管式） | 最高 |
| `[服务端]SCNETx26.06.19z1.zip` | 根目录 `Survivalcraft.dll`（托管式） | 次之 |
| `[服务端][Windows]PocketSurvival-*.zip` | C++/`PSTerminal.exe` 变体 | 极低 |

### 3.7 手动上传版本包兜底

`POST /api/versions/upload`（multipart `file` + `mode/name/instanceId/preserve`）：
上传 zip/tar.gz → 解压安装（新建或覆盖）。实测上传含 `Survivalcraft.dll` 的包，
新建实例目录含二进制：

```
instanceId=5ab45950-... name=m6-upload-...
hasdnl=true
```

覆盖既有实例：先写入哨兵配置 `Configs/__m6_sentinel.json`，覆盖安装后仍存在
（`sentinelKept=true`），证明**保留 Configs/Worlds/Plugins/备份**语义正确。

### 3.8 失败错误可读

```
POST /api/versions/download { asset: '不存在的资源.zip' } → task.phase=failed
  error=版本 x26.06.19 不包含资源: 不存在的资源.zip
```

错误路径：网络非 2xx（`下载失败：HTTP 404 ...`）、体积超限（`资源体积超过上限`）、
下载不完整（`下载不完整：期望 N 字节，实际 M 字节`）、解压缺二进制
（`版本包缺少 Survivalcraft.dll`）。均记录到任务 `error` 字段并可经轮询读取。

### 3.9 进度与任务列表

- 任务含 `phase/receivedBytes/totalBytes/percent/speedBps`，前端 1s 轮询 `GET /versions/tasks`。
- 进度阶段：`queued → downloading → extracting → installing → done|failed`。

## 6. 交付物（M6）

- **共享类型（packages/shared/src/version.ts，新）**：`VersionSourceId`/`ServerPlatform`/
  `ReleaseAsset`/`ReleaseInfo`/`ReleaseListResponse`/`CreateDownloadInput`/`DownloadTask`/
  `InstallMode`/`UploadInstallInput`/`VersionSourceInfo`；`InstanceSource` 扩展 `'version'`。
- **后端（apps/api/src/version/）**：
  - `version-source.ts`：来源接口 + asset 识别/平台/架构/评分（`serverPackageScore`）。
  - `gitee-source.ts`：Gitee Releases 拉取；`GITEE_MIRROR` 支持第三方镜像 host 替换。
  - `version.service.ts`：release 列表（内存 + 磁盘缓存、失败降级）、asset 解析、主机平台预选。
  - `download.service.ts`：流式下载（进度/速度/ETA/体积上限）、解压安装（新建/覆盖）、
    手动上传兜底、任务状态机。
  - `version.controller.ts`：`GET sources/releases/tasks/:id`、`POST releases/refresh/download/upload`。
  - `version.module.ts`；`app.module.ts` 注册（置于 `InstanceModule` 之前）。
  - `config/env.ts`：新增 `VERSION_SOURCE`/`VERSION_CACHE_MS`/`VERSION_MAX_BYTES`。
  - `instance.service.ts`：`createFromVersion`、`overwriteInstall`（整目录快照 + 保留受保护目录）；
    `applyMetaToConfig` 增加配置文件播种（`ensureSettingsXml`/`ensureServerSetting`）
    与世界缺失时 `AutoGenerateWorld=true`。
  - `server-config.service.ts`：新增 `ensureSettingsXml`/`ensureServerSetting`（create-if-missing）。
- **前端（apps/web）**：`pages/versions.vue`、`components/version/VersionsPanel.vue`、
  `layouts/default.vue` 新增「版本」导航。
- **运维**：`apps/api/scripts/m6-gate.cjs`（门禁脚本）、`docs/test-reports/M6.md`（本文件）。
